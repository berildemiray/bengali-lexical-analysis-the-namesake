# A Corpus-based Computational Analysis of Bengali Lexical Elements in *The Namesake*
Conducted by: Tutku Beril Demiray

## Project Overview

This mini project presents a corpus-based computational analysis of Bengali lexical elements and culturally marked multilingual expressions in *The Namesake* by Jhumpa Lahiri. Using Python and basic Natural Language Processing (NLP) techniques, the project investigates the frequency, distribution and contextual usage of Bengali lexical items embedded within English discourse throughout the novel. The project combines corpus linguistics, multilingual text processing and literary analysis in order to examine how multilingual lexical practices contribute to the representation of diasporic identity, cultural belonging and hybrid linguistic environments.

---

## Research Aim

The main aim of the project is to analyse Bengali lexical elements appearing throughout *The Namesake* through a corpus-based computational approach and to investigate how these multilingual lexical patterns contribute to the construction of cultural identity and diasporic belonging within the narrative.

---

## Research Question

How do Bengali lexical elements function within the English-language discourse of *The Namesake*, and what do their frequency and distribution reveal about multilingual identity and cultural representation in the novel?

---

## Methodology

The project was carried out using Python in Google Colab. The corpus text was processed through basic NLP techniques including:

- text preprocessing
- tokenization using NLTK
- lexical extraction
- lexical frequency analysis
- multilingual lexical categorisation
- data visualization using matplotlib

The selected lexical items were manually identified according to their sociolinguistic and cultural relevance within the novel.

---

## Corpus Categories

The extracted Bengali lexical elements were analysed according to several semantic and cultural categories, including:

- kinship terminology
- cultural objects
- food-related vocabulary
- geographical references
- ceremonial and identity-related expressions
- multilingual lexical insertions

---

## Main Findings

The corpus analysis revealed that Bengali lexical elements appear consistently throughout the novel and function as important markers of multilingual identity and cultural continuity.

Key findings include:
- The lexical item “Bengali” appears with the highest frequency within the corpus, suggesting that linguistic and cultural identity constitute central thematic concerns of the narrative.
- Kinship terminology such as baba, daknam and bhalonam occurs frequently in family-related interactions.
- Cultural lexical items such as sari, dal, tiffin and pajamapunjabi preserve culturally specific meanings within English discourse.
- Most multilingual insertions occur at lexical level while English remains the dominant grammatical structure of the novel.
- Geographical references such as Calcutta and Gariahat function as markers of cultural memory and diasporic attachment.

The project further demonstrates how corpus-based lexical analysis can support literary interpretation by providing quantitative linguistic evidence for multilingual and identity-related patterns within literary texts.
